Design System Reference

温暖白底 · 理想绿 · 圆润友好.

理想汽车的视觉语言: 暖白基底 + 理想绿 (#2A7E3F) 主调 + 暖橙 secondary, 强圆角 12-32px, 圆润柔和, 强调家的温度与场景感. 拒绝跑车科技, 拥抱家庭温度.

View DESIGN.md ↗

Color

理想色板: 深绿 (家庭, 自然, 稳重) + 暖橙 (情感 highlight) + 暖白基底. 不使用冷蓝 / 大红 / 纯黑, 所有色彩传达"家"的温度.
