冷静、克制、值得信赖的企业蓝

腾讯云的视觉语言用单一的腾讯蓝 #006EFF 锚定专业感:大量留白、4–8px 圆角、克制的渐变、isometric 3D 插画。每一个 token 都为"产业互联网"这一叙事服务。

查看 DESIGN.md ↗

色彩

以白为底,以蓝为锚。腾讯蓝 #006EFF 比阿里云 #FF6A00 更冷感,与企业级服务的稳定感一致。仅在 CTA、图标、链接等功能性场景使用主色。
