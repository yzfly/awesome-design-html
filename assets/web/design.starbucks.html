Design System Reference

Warm cream, four greens, one floating pill.

Starbucks's system is disciplined about where each green goes — Starbucks for headings, Accent for CTAs, House for bands, Uplift for decoration. Gold appears only for Rewards ceremony. Below: the tokens behind the café.
