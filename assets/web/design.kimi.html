Design System Reference

暗面与边缘光 · 工程师气质的宇宙

月之暗面的设计语言是字面意义的 "dark side of the moon": 深空黑画布, 月球大部分隐在阴影里, 只露一道青色边缘光. 克制, 理性, 带一点登月工程的浪漫 — 它不试图可爱, 它试图可信.

View DESIGN.md ↗

Color

三层结构: 深空黑做画布, 月光银白做文字, 月相青做唯一强调色. 青色用量极克制 — 只出现在主操作, 状态点与边缘光上, 大面积留给黑与灰, 像夜空只有一弯亮边.

Typography

Inter + Noto Sans SC 承担界面, JetBrains Mono 承担模型名, 参数与代码 — 等宽字体是这套语言里的 "工程师口音". 标题最重只到 700, 靠收紧的字距而非加粗传递力量.

Voice & Tone

月之暗面的文字气质是 "登月工程师": 谈使命时有诗意, 谈产品时只给事实. 不喊口号, 用模型参数, 开源权重和真实工作成果说话.

理性
"1T 总参数, 256K 上下文" 给参数不给形容词.
"开源权重" 是承诺, 不是营销词.
能用数字, 就不用副词.
克制的浪漫
"寻求将能源转化为智能的最优解" — 使命可以宏大.
名字致敬 Pink Floyd, 但页面上没有一处多余的装饰.
浪漫在世界观里, 不在 UI 里.
结果导向
"真实的工作, 不止于聊天" 强调交付物.
"帮我研究, 输出一份报告" 而非 "和我聊聊".
动词永远指向成品.

Components

青色实心按钮承担唯一主操作, 月光白按钮做次级强调, 其余全部描边或幽灵态. 输入框黑底细描边, 聚焦时亮起青色光圈. 标签分青色 (状态), 等宽 (参数), 月白 (强调) 三类.
