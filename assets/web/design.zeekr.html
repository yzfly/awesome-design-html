Design System Reference

Pure Black. Pure White. One Blue.

极氪的视觉语言: 拒绝任何花哨. 几乎纯黑白单色系, 大字号几何 sans 字体配 -2.5px 负字距, 锋利的 4-8px 圆角, 唯一的极氪光蓝 (#0061FF) 作为功能 accent. Apple + Porsche Taycan 混合, 国产豪华电车设计天花板.

Color

单色系 + 单一 accent 蓝. 黑与白是 hero, 灰阶承担层级, 极氪蓝 (#0061FF) 仅在关键交互, 数据高亮和品牌锚点上出现. 拒绝多余色彩, 让形式本身成为语言.

Typography

Inter / Helvetica Neue 配合 Noto Sans SC. 大标题 700 配 -2.5px 字距 (-4px 在最大尺寸), 营造几何精密感. 小号文字反而轻盈 (400-500). 全篇大量使用 uppercase + letter-spacing 强化冷峻感.
