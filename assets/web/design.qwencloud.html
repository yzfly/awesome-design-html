Design System Reference

Spectrum violet · light surface ladder · dark pill

Qwen Cloud differs from the consumer Qwen page on three axes: (1) a four-stop horizontal violet→magenta→purple→blue spectrum reserved for keywords and analyst eyebrows, (2) a near-monochrome light surface ladder (#FFF → #FAFBFD → #F2F4F8) with featherweight 24px / 56px shadows, and (3) a dark pill CTA (#0B0C0F) instead of the gradient pill used on consumer surfaces. Enterprise feel without losing the brand spectrum.

View qwencloud.com ↗

Color

The spectrum gradient is the brand. Use it only on one word per heading — “next”, “Why”, “leading position”. Body type stays full-contrast ink. Surfaces are nearly monochrome to let the spectrum carry all the chromatic weight.

Model cards land at 24px, hero stage at 24px, final CTA band at 32px, all buttons pill. Smaller 8–14px reserved for inline chips and code surfaces.

Components

The CTA hierarchy is dark-pill (primary) → white-bordered pill (secondary) → soft-gray pill (tertiary). The spectrum gradient is reserved for tags, mark dots, and the violet-card model art — never as a button fill (that's the consumer Qwen page).
