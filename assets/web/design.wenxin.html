Design System Reference

蓝紫梦幻 · 知识增强的视觉语言

文心一言的视觉系统由百度蓝出发, 向紫色过渡, 偶尔触及粉色高光. 这套渐变体系是知识增强大模型的视觉具象 — 蓝色稳重, 紫色想象, 粉色未来.

View DESIGN.md ↗

Color

蓝紫双色渐变是文心的视觉签名. 主色从百度蓝 #2932E1 一路过渡到紫色 #8E63FF, 偶尔加入粉色 #E63DBF 作为强调. 渐变方向永远是 135deg, 保持视觉一致.
