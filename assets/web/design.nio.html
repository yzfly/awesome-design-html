Design System Reference

白底优雅 · 天空蓝 accent · 高端克制.

蔚来的视觉语言: 大量留白, 极简白底配天空蓝 (#0085FF / #00BFFF), 偶尔以黑色高端 tile 出现. 字体几何 sans, 中性中带克制, 不卖配置, 卖归属感.

View DESIGN.md ↗

Color

蔚来色板由 NIO 蓝 (天空与地平线) + 黑色 + 大面积白与浅灰组成. 严格不使用橙红等暖色, 通过冷调与留白传达高端感.

Typography

Inter + Noto Sans SC. 偏好 500-600 中等几何字重, 不用 800 极重. 让字体本身保持优雅, 标题以负字距与大字号制造仪式感.
