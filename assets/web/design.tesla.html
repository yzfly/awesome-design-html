Design System Reference

结构即品牌: 全屏纵向的电影脚本

Tesla 的辨识度不在配色, 在信息架构本身: 一屏一辆车, 滚动即换幕. 每一幕的剧本完全相同 — 名字, 一句话, 一辆车, 三个数字, 两枚按钮 — 重复本身成为节奏, 黑与银交替成为剪辑. 页面不解释产品, 它放映产品.

Color

两块幕布轮流登场: 影院黑与银幕灰. 文字只有一种墨色和它的灰阶. 彩色被压缩到极限 — 蓝色只给链接与状态, 红色只属于词标. 当整个页面接近无彩, 车身的一道高光就是最亮的颜色.

Typography

Inter 全场, 一种字体演完整部电影. 层级不靠字体切换, 靠尺寸与字距的两极: 车型名舒展, 规格数字收紧, 按钮全大写却只有 12px — 命令式的内容, 耳语式的音量.

Components

组件只有一对 CTA, 一组规格, 一条导航 — 因为每一幕都只需要这三样. 半透明加背景模糊让按钮浮在任何画面上而不遮挡它; 规格组用细竖线分隔, 数字大, 标签小而疏.

Voice & Tone

Tesla 的文案像规格表一样寡言. 每一幕只允许一个名词和一句陈述, 其余交给数字 — 不形容, 不感叹, 不挽留.

名词即句子

"Model S." 车型名加句号就是完整的标题.
tagline 限一句, 不超过八个词.
没有欢迎语, 没有 slogan 轰炸.

数字替代形容词

不说 "极致性能", 说 "2.1 s".
不说 "超长续航", 说 "634 km".
规格本身是诗, 形容词是杂音.

大写的低语

"CUSTOM ORDER" — 全大写却只有 12px.
字距拉开到 0.2em, 音量降到耳语.
命令式的内容, 克制的声压.
