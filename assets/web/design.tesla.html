Design System Reference

Radical subtraction. One blue. All else white.

Tesla's interface earns its calm through omission — no shadows, no gradients, no decorative color. Universal Sans, one accent blue, and 4px corners. Below: the tokens behind the silence.

Typography

Universal Sans Display + Universal Sans Text (substituted with Inter). Only weights 400 and 500. Letter-spacing stays at "normal" everywhere — Tesla trusts the typeface to speak for itself.

Components

The full vocabulary: Primary blue CTA paired with secondary white, transparent nav buttons, and a transparent text-link variant. No shadows, no scale animations — every transition is a color shift over 0.33s.
