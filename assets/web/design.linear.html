Set the pace

Designed to move at the speed of thought.

Every interaction surface is built around a keyboard-first input model. The mouse is for when you can't help it.

Command menu

Anything you can do, you can do from ⌘K. Issues, projects, settings — keyboard-first by design.

Cycles

Lightweight time-boxed sprints with automatic rollover. Stop bike-shedding the sprint, start shipping it.

Global at the core

Realtime sync across web, desktop, and mobile. Your view stays right whichever surface you're on.

Issue-first

Every roadmap, milestone, and project comes back to a single, well-formed issue. The atomic unit of progress.

Built for teams

Roles, mentions, assignment, sub-issues — all the choreography a team needs without a project-management certification.

API + integrations

GitHub, Figma, Slack, and a clean GraphQL API for everything else. Linear plays well with the rest of your stack.

Build page

A changelog you'd actually read.

Every change shipped on the platform, written by the team that built it.

2025.18.0Mar 12, 2026

Inbox is now realtime Shipped

Replaced polling-based unread counts with a server-pushed channel. Inbox bell updates within 80ms of a new mention or comment. Available on web and desktop today; mobile rollout begins this week.

2025.17.4Mar 6, 2026

Cycle health: new at-a-glance row Shipped

A compact strip at the top of each cycle showing carry-over, in-flight, and at-risk counts. Tap the strip to drop into the at-risk view. Available to all teams on the Standard plan and above.

2025.17.0Feb 28, 2026

Initiatives → Projects mapping

Initiatives now roll up across projects with a single source of truth for status. The transition is automatic for workspaces with the labeling convention already in place; everyone else gets a one-click migration in settings.
