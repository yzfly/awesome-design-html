Typography

Pin Sans is proprietary; Inter (400/500/600/700) is the closest open-source substitute. Apply -1.2px tracking at display sizes regardless of substitute. The system has a steep size jump: display-xl drops directly to body-md with no intermediate tier on the home hero.

display-xl70 / 600 / 1.10 / -1.2pxCreate the life you love
display-lg44 / 700 / 1.15 / -0.8pxWhere your content can thrive
heading-xl28 / 700 / 1.20 / -1.2pxBring your favorite ideas to life
heading-lg22 / 600 / 1.25Welcome to Pinterest
heading-md18 / 600 / 1.30In-grid pin label
body-md16 / 400 / 1.40Default body. Hierarchy is from weight, not from color tint.
body-strong16 / 600 / 1.40Primary nav link, form label
body-sm14 / 400 / 1.40Footer copy, pin metadata, helper text.
caption-md12 / 500 / 1.50Caption, link metadata
button-md14 / 700 / 1.00Sign up

Radius

Three values in active use: 16px on every interactive element + standard card, 32px on large pin cards + modals, pill for circular elements. There are no sharp-cornered buttons in the system.
