Design System Reference

紫粉渐变 · 阿里二次色 cyan

Qwen 的视觉语言以紫色为主轴, 向粉色延伸, 偶尔出现 cyan 作为强调色. 这种 "主紫 + 副 cyan" 的双轨色彩策略让界面既有阿里大厂的稳重, 又带技术品牌的灵动.

View DESIGN.md ↗

Color

主色采用紫粉渐变, 从 #615CED 紫到 #C44CFF 粉, cyan #1ED5FF 作为二次色, 偶尔点缀于按钮和数据可视化场景, 避免与主紫色直接冲突.

Typography

PingFang SC + Inter 双字族, JetBrains Mono 处理代码与数据. 主标题 600-800 重量级, 配合渐变文字, 既保留科技品牌的力量感又不过分压迫.
