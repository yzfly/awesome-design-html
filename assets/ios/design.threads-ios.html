iOS Surface Anatomy

Three surfaces. Hairline between each idea.

Threads's app prizes typographic restraint above all. There are no card shadows, no rounded backgrounds for posts, no accent colors saying "look here." Just text, a hairline below it, and the next thought.

For you

Two-tab strip (For you · Following) with white-underline active state. Posts sit edge-to-edge on the black canvas, separated only by a 1px hairline at #1f1f1f. No card chrome, no shadows.

Activity

Eight filter chips (All / Follows / Replies / Mentions / Quotes / Reposts / Verified / Likes) — outline by default, white-fill on active. Rows show a tiny colored badge in the avatar's bottom-right corner indicating event type.

Profile

Name big 24/800, handle 13/500 muted, Instagram-handle pill (the only "card" on the page). Bio + follower count + mutual-follower avatars. Edit/Share buttons are outlined — never filled.

Multi-part thread

A pole that connects one idea to the next.

When a user posts a thread of replies to themselves, Threads renders a 2px vertical pole between each avatar, anchoring child posts to their parent. The pole is the only "structural" graphic in the app — everything else is just type.

The pole color is the same hairline gray (#252525) used for post separators — it has to be visible but never demand attention.

width: 2px color: #252525 radius: 1px margin: 4px from avatar

Quote card

A second voice, framed in a hairline.

When a user quotes another post, the quoted content renders inside a 1px-bordered rounded rectangle — the ONLY card-like surface in the app's content stream. The card is 14px radius, sits flush with the body text, never carries a fill.

If the quoted author is verified, the blue check appears at the inline baseline. Original post timestamp is right-aligned in the card header.

border: 1px #252525 radius: 14px padding: 14px fill: transparent
Activity filter chips

Eight states, one row, no panic.

The Activity screen uses an outline-by-default, fill-on-active chip system — 8 chips that scroll horizontally without ever wrapping. Active chip swaps to white fill with black ink. Border color matches the canvas surface ladder.

The chips never use brand colors; the system stays purely monochrome so the activity content (avatars + body text) gets every drop of attention.

idle: border #252525 active: fill #fff radius: 9999px padding: 6 × 14

Design System Reference

Black, white, hairline. And exactly two accent colors.

Every token Threads's iOS app reaches for — surface ladder, type ramp, radius scale, components. Inherited Meta-blue verified check and Instagram-red heart are the only chromatic notes — everything else is built from a five-stop gray ladder.

Typography

Meta's homegrown Inter (literally — Threads uses Inter as the system font, no substitution needed). Display 22-24 for screen titles. Body 15/400 with comfortable line-height. Display name 15/600, handle 15/400 muted.

Radius

The card was not invented in this app. The only radius that matters lives in two places: media (12px) and the quote-card (14px). Everything else is either a circle (avatar, like burst) or a pill (chip, button) or a flat hairline.

iOS Spec Strip

The constants that anchor the iOS implementation.

Post separator
1px
Hairline #1f1f1f. No padding bleed — sits flush with screen edges.
Avatar (feed)
34pt
36pt on Activity rows. 54pt on Profile. Always perfect circle.
Thread pole
2pt
Connects parent → child in self-replies. Color matches separator.
Action stroke
1.6pt
Heart, reply, repost, share — all outlined. Hearts fill on tap.
Quote card
14pt
The only card-like surface. 1pt border, no fill.
Filter chip
28pt
Height. Pill shape. Outline → white-fill on active.
Tab indicator
1pt
White underline, 30-70% of tab width, centered.
Animation
spring
0.5 response, 0.85 damping. Subtle — Threads is anti-bouncy.

Components

A vocabulary that refuses ornament. Buttons are either white-on-black (primary) or outlined-on-black (secondary). No fills. No gradients.
